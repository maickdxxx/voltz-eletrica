# Voltz Elétrica

Template público do Coruja Host para eletricistas e empresas de serviços elétricos.

## Stack

- React + TypeScript + Vite
- React Router
- Contrato Universal Coruja Host v2

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Saída: `dist/`.

## Coruja Host

O contrato está em `coruja.template.json` e os arquivos de edição em `src/coruja-template/`.
Todos os conteúdos comerciais editáveis vêm de `defaults.json` e são lidos pelo renderer em tempo real, incluindo patches do editor visual.
